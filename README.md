# Vehicle Rental Backend API

A backend API for a vehicle rental system built using Node.js, Express.js, and MongoDB.

## Features

- User registration and authentication
- Secure password hashing using bcrypt
- JWT-based authentication
- Vehicle management
- Vehicle booking and availability tracking
- RESTful APIs
- Email functionality using Nodemailer
- API documentation using Swagger
- Application logging using Winston

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Nodemailer
- Swagger
- Winston
